# GoFlow

GoFlow is a staged learning project for building a production-style Go backend that accepts jobs, stores them, processes them asynchronously, retries transient failures, and surfaces operational behavior cleanly.

The project follows the roadmap in `Go_Industry_Roadmap_4_Weeks.md`. It starts as a small CLI so the early modules can focus on idiomatic Go foundations before expanding into HTTP APIs, PostgreSQL, concurrency, graceful shutdown, and production-readiness concerns.

## Current status

Roadmap initialization is complete. The current learning focus is Week 1, Module 1.1: environment, packages, modules, and tooling.
